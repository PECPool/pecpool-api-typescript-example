# Changelog

All notable changes to this example repository are documented here.

## 1.0.0 — 2026-08-25

- Added a strict TypeScript client for Node.js 22 and newer.
- Implemented the public PECPool HMAC-SHA256 signing contract.
- Added typed helpers for every documented PECPool API v1 endpoint.
- Added an ESM command-line example with built-in `.env` support.
- Added deterministic offline signing, URL, transport, and error tests.
- Added security, contribution, API, GitHub, and AI-readable documentation.
